## 一、背景与问题

### 1.1 现状问题
v10 完成了技能选择面板（3 主动选 1 + 2 被动选 1）的 UI 和数据链路，但存在以下未解决问题：

1. **技能未按 HP/atk/def 体系重设计**：现有技能仍沿用 v4 的"概念设计"，未适配 HP 战斗体系（伤害数值、治疗比例、buff 持续回合均未校准）。
2. **角色图鉴不完整**：`renderCodexDetail` 仅展示 `ch.skill`（默认第 1 个主动），未展示全部 3 个主动技能 + 2 个被动技能；B 王需展示 5 个主动技能。
3. **技能描述含英文/函数名**：部分技能描述出现 `debug`、`catch`、`crash` 等英文 ID，需统一为中文名。
4. **新手教程未更新**：教程仍为旧版，未涵盖 HP 体系、技能选择、buff 系统、棋子合并等新机制。
5. **技能选择生效 bug**：选将面板选择第 2/3 主动技能后，进入游戏 HUD 仍显示默认技能——需排查 `state.playerActiveSkill` 是否被正确读取。

### 1.2 设计目标
- 所有 18 角色的 3 主动 + 2 被动技能按 HP 战斗体系重设计数值。
- 技能伤害区间：30–150（按 CD 和目标范围缩放）。
- 治疗/护盾：30–50% 最大 HP。
- Buff/Debuff 持续：1–3 回合。
- 角色智力（int）影响技能伤害：`最终伤害 = 基础伤害 × (1 + int/200)`。
- 每个角色的 3 个主动技能提供不同战术取向（信息/辅助、战术、强攻）。

## 三、技能选择生效修复

### 3.1 问题根因
`getActiveSkillForCurrentPlayer()` 已正确读取 `state.playerActiveSkill`，但以下场景导致不生效：

1. **三英模式**：`state.playerActiveSkill` 仅保存最后一位武将的技能，轮换时未切换。
2. **HUD 对方技能显示**：PVP 模式下 `ai-skill-name` 仍显示 `p2Char.skill.name`（默认技能），未显示对方选中技能。
3. **状态未初始化**：`state.playerActiveSkill` 未在 state 初始定义中声明，可能被 GC 或重置覆盖。

### 3.2 修复方案
1. 在 state 初始化中添加 `playerActiveSkill:null, playerPassiveSkill:null`。
2. 三英模式：为每位武将单独存储技能（`state.threeHeroSkills = [{active, passive}, ...]`）。
3. PVP 对方技能显示：读取 `state.pvpBlackActiveSkill` / `state.pvpRedActiveSkill`。

## 四、角色图鉴修复

### 4.1 问题
`renderCodexDetail` 中 `skillList` 仅取 `[ch.skill]`，未展示 `ch.actives`（3 个主动）。

### 4.2 修复方案
```javascript
// 修复前
const skillList = (cid==='bking' && ch.skills && ch.skills.length) ? ch.skills : [ch.skill];

// 修复后
let skillList;
if (cid === 'bking' && ch.skills && ch.skills.length) {
  skillList = ch.skills;  // B王展示全部
} else if (ch.actives && ch.actives.length) {
  skillList = ch.actives;  // 其他角色展示3主动
} else {
  skillList = [ch.skill];  // 兼容旧数据
}
```

同时修复技能描述中的英文 ID，确保全部使用中文名。

## 五、新手教程更新

### 5.1 教程步骤（8 步）
1. **欢迎**：游戏简介
2. **模式与解锁**：故事模式（初始 3 角色）、PVP、阵营、三英战 B 王；PVE 需通关故事模式
3. **选棋与操作**：点击棋子查看可走位置，点击菜单选择"移动"/"攻击"/"详情"
4. **移动与吃子**：选棋→选目标→确认；攻击时扣 HP
5. **兵种相克**：核心/进攻/远程/防守/特殊，相克增伤
6. **HP 与战斗体系**：棋子有 HP/atk/def，攻击时 `伤害 = atk - def`，HP 归 0 阵亡
7. **角色属性与技能选择**：点击角色卡选 3 主动 1 + 2 被动 1，属性加成到棋子
8. **Buff 与棋子合并**：buff 双方显示，棋子合并 HP 叠加
