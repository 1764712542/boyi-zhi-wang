# v29 平衡性调整与角色扩展

## 背景

用户反馈多个问题：
1. 文档约束与游戏实际实现不一致（硬性约束.md 棋子数值仍为v26版本，与data.js v28不符）
2. 部分角色"实在太强了，很难杀死"，角色梯度差异过大
3. 故事模式章节未按角色数量扩展
4. 故事模式定位错误（不存在主角，而是各角色对战B王）
5. B王技能缺乏差异化，应体现"傲慢、贪婪、愚蠢、装逼、自视清高"等负面人性
6. 炮可直接打马，马处于极端劣势
7. 需新增3个角色：张树灿（内敛）、张毓芝（平稳）、刘锋（搞子）

## 修改内容

### 一、文档约束修正（硬性约束.md）
- 棋子数值表更新为v28版本（与data.js PIECE_STATS 一致）
- 英雄类型表补全：增加 liuqi（大汉棋圣）、daaixianzun（大爱仙尊）、broly（布罗利）、empire（帝国元首）
- 角色强度梯度更新为20个角色
- 故事模式章节从14章扩展到20章
- 删除"斗破苍穹式网文套路"描述，改为"班级群像喜剧风"
- B王人设改为"集齐人性中所有不好的点"

### 二、炮马平衡（engine.js calcDamage）
**问题**：炮攻击马时
- 炮基础伤害 = 80 × 1.2 = 96
- 炮无视50%防御，马防御20→剩10→被无视5→剩5点防御
- 实际伤害 = 96 - 5 = 91，几乎一击秒杀马（HP=100）
- 炮打非远程不掉血，马无法反击

**调整方案**：v29-马·骑兵闪避
- 给马添加对远程攻击的25%闪避概率（仅对炮有效）
- 马 HP 100 → 110（小幅增强生存）
- 该闪避仅在真实战斗（doMove）中触发，AI 模拟禁用，保证搜索稳定

### 三、角色梯度重排（data.js）

**目标**：缩小S+与常规角色差距，避免"难以击杀"

**当前问题**：
- S+ 角色 atk/def/int 全部 95-100，常规角色 80-92
- 仙帝Alice、大爱仙尊 HP 加成过高（智力系HP×1.0，但int=100，普攻真伤=int×0.8=80，几乎秒杀常规角色）

**调整方案**：
- S+ 角色 atk/def/int 从 99/99/100 调整为 96/96/98（仍最强，但差距缩小）
- 帝国元首 95/75/92 → 93/78/90
- 布罗利 98/82/55 → 95/85/55（保留"野性"特色，谋不变）
- 常规角色 atk 普遍 +2~4，def +3~5（缩小与S+差距）
- 部分强度过低角色（如周子翰、唐昊博涵）适当提升

### 四、B王差异化重设计

**人设**：傲慢、贪婪、愚蠢、装逼、自视清高（集齐人性中所有不好的点）

**新主动技能**（覆盖原5个）：
1. **傲慢·目中无人**（替换 flex）：B王气场压制对方全体，下回合对方攻击-25%，且B王下次攻击+30%
2. **贪婪·夺人所爱**（替换 swap）：窃取对方一个永久buff给己方，且B王回复30%最大HP
3. **愚蠢·自作聪明**（替换 selfreverse）：随机禁用己方一个非王棋子1回合（自损），但B王下次攻击造成双倍伤害
4. **装逼·虚张声势**（替换 domain）：3回合内对方全体攻击-30%，且每回合30%概率走错
5. **自视清高·指鹿为马**（保留 swap 核心）：强制对方下回合走B王指定的位置

**新被动技能**：
1. **傲慢气场**：光环，对方攻击-10%（保留 p_aura）
2. **厚颜无耻**：每局2次免疫沉默（保留 p_shameless）
3. **贪婪本性**：每吃一子，B王下次攻击+15%（新被动 p_greedy）
4. **愚蠢运气**：被吃时25%概率反吃对方（新被动 p_stupid_luck）
5. **自视清高**：永久光环，B王攻击每回合+5%递增（保留 p_bking_insight）

### 五、新增3个角色（data.js）

#### 1. 张树灿（内敛）- 力量系
- 性格：内敛沉稳，话少但招招致命
- stats：atk 88 / def 84 / int 80
- 主动技能：
  - 沉默气场（默认）：沉默B王2回合，且B王下次攻击-20%
  - 内敛蓄势：选己方一颗棋子蓄势，2回合后下次攻击+80%
  - 静水流深：3回合内己方全体攻击+20%，且每回合恢复30HP
- 被动：内敛气场（光环，己方全体防御+15）/ 深思熟虑（每3回合获得50点护盾）

#### 2. 张毓芝（平稳）- 智力系
- 性格：平和稳重，攻守平衡
- stats：atk 86 / def 84 / int 88
- 主动技能：
  - 均衡之力（默认）：己方全体攻击+15%防御+15%（2回合）
  - 中庸之道：互换双方一颗强弱子位置，且己方下回合连走两步
  - 稳健布局：己方帅获得150点护盾，且己方全体攻击+25%（2回合）
- 被动：稳健气场（光环，己方全体每回合恢复10HP）/ 平和心态（被吃时20%闪避）

#### 3. 刘锋（搞子）- 敏捷系
- 性格：搞子，玩世不恭但暗藏杀机
- stats：atk 90 / def 70 / int 80
- 主动技能：
  - 搞子之术（默认）：随机交换两颗敌方棋子位置，且B王下回合无法吃子
  - 混乱投掷：随机使对方一颗棋子沉默2回合，且该子下回合攻击-30%
  - 出其不意：己方一颗棋子瞬移到对方区域任意空位，且该子下回合攻击+50%
- 被动：搞子气场（光环，对方全体每回合5%概率走错）/ 不按套路（每3回合获得攻击+30% buff）

### 六、故事模式扩展（14 → 20章）

新增6个章节，每个新角色对应一章，按性格强度递增：
- 第15章：张树灿（内敛深沉）
- 第16章：张毓芝（中庸平衡）
- 第17章：刘锋（搞子突袭）
- 第18章：布罗利（传说觉醒）
- 第19章：帝国元首（铁血独裁）
- 第20章：终章·仙帝Alice与大爱仙尊（双仙帝合战B王）

每章对应B王层数：
- 15-16章：4层（钻石装+）
- 17-18章：5层（王者装）
- 19章：5层+（王者装+ 强化）
- 20章：6层（仙帝级B王，新增属性加成）

通关后解锁全部角色。
