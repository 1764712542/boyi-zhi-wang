## 二、P1-1 帅遗言 Bug 修复（bugfixer）

### 问题诊断

当前 calcDamage 中帅被吃时与其他棋子一样走 passivesOnCaptured 流程，但：
1. 帅被吃 = 游戏立即结束，passivesOnCaptured 中的「遗言」效果无意义
2. 帅的「临终一击」（反伤50点）永远不会触发

### 修复方案

**方案：改为战前光环 + 被攻击时触发**

1. **指挥光环（战前）**：帅存活时，相邻己方单位 atk+10%（已有 defenseBoost +10）
2. **核心守护（战前）**：帅存活时，己方全体每回合回 maxHp×3%
3. **临终反击（被攻击时触发，非被吃后）**：
   - 帅被攻击时（无论是否被吃），攻击方受 50 点反伤
   - 在 calcDamage 中实现：若 defender.type === 'k'，attackerDmg += 50
   - 这样即使帅被一击必杀，攻击方也会受伤

### 涉及代码

- `engine.js calcDamage`：新增帅被攻击时反伤逻辑
- `skills.js applyKingCommandAura`：扩展为核心守护+指挥光环
- `data.js`：PIECE_STATS.k 保持不变（260/50/55）

## 三、P2-1 7 兵种极大差异化（unitbalancer）

### 参考游戏

- **Dota2**：英雄属性差异化（力量/敏捷/智力）
- **LoL**：装备与定位差异化（坦克/战士/刺客/法师/辅助）
- **火焰纹章**：武器三角相克（剑克斧克枪克剑）

### 兵种差异化方案

#### 1. 帅/将 k（指挥核心）

| 属性 | 数值 | 说明 |
|------|------|------|
| HP | 260 | 高血量 |
| atk | 50 | 中等攻击 |
| def | 55 | 中等防御 |
| type | core | 核心 |

**独特机制**：
- 「指挥光环」：相邻己方单位 atk+10% + def+10
- 「核心守护」：己方全体每回合回 maxHp×3%
- 「临终反击」：被攻击时攻击方受 50 点反伤（无论是否被吃）

#### 2. 车 r（玻璃大炮）

| 属性 | 数值 | 说明 |
|------|------|------|
| HP | 120 | 中等血量 |
| atk | 90 | 高攻击 |
| def | 0 | 零防御 |
| type | striker | 进攻 |

**独特机制**：
- 「一击必杀」：车攻击非 defender/core 时，defenderDmg = maxHp
- 「自损」：车攻击时自损 maxHp×20%
- 「攻坚」：车攻击 defender 时，伤害改为 maxHp×50%，自损减半（10%）
- 「破釜」：车 HP < 30% 时，atk+50%（背水一战）

#### 3. 马 h（刺客型）

| 属性 | 数值 | 说明 |
|------|------|------|
| HP | 100 | 中等血量 |
| atk | 60 | 中等攻击 |
| def | 20 | 低防御 |
| type | striker | 进攻 |

**独特机制**：
- 「跳跃攻击」：不触发防守方反击
- 「真实伤害」：攻击附加 25 点真实伤害（无视 immune/shield）
- 「突袭」：马攻击后可后撤 1 格（可选，不消耗移动力）
- 「破甲」：马攻击时无视 30% 防御（与车共享）

#### 4. 炮 c（远程射手）

| 属性 | 数值 | 说明 |
|------|------|------|
| HP | 80 | 低血量 |
| atk | 80 | 高攻击 |
| def | 12 | 低防御 |
| type | remote | 远程 |

**独特机制**：
- 「远程攻击」：打非远程不掉血
- 「伤害加成」：炮伤害 ×1.2
- 「闪避」：被近战攻击时，闪避 +15%
- 「隔山打牛」：炮攻击时无视防守方 50% 防御

#### 5. 仕/士 a（贴身护卫）

| 属性 | 数值 | 说明 |
|------|------|------|
| HP | 100 | 高血量 |
| atk | 30 | 低攻击 |
| def | 75 | 高防御 |
| type | defender | 防守 |

**独特机制**：
- 「贴身肉搏」：反击伤害 +50%（counterMul = 1.5）
- 「替身守护」：相邻帅被攻击时，士可代为承受（每局 1 次）
- 「免疫一击必杀」：被车攻击时，伤害改为 maxHp×50%
- 「坚守」：士在九宫格内时，def+20%

#### 6. 相/象 e（远程支援）

| 属性 | 数值 | 说明 |
|------|------|------|
| HP | 100 | 高血量 |
| atk | 35 | 低攻击 |
| def | 65 | 中高防御 |
| type | defender | 防守 |

**独特机制**：
- 「支援光环」：每回合给相邻己方单位 +5 def（光环）
- 「斜走攻击」：不触发防守方反击
- 「免疫一击必杀」：被车攻击时，伤害改为 maxHp×50%
- 「反制」：相被攻击时，30% 概率反弹 20% 伤害

#### 7. 兵/卒 p（特殊战士）

| 属性 | 数值 | 说明 |
|------|------|------|
| HP | 140 | 高血量 |
| atk | 50 | 中等攻击 |
| def | 15 | 低防御 |
| type | special | 特殊 |

**独特机制**：
- 「韧性」：受非帅攻击只受 50% 伤害
- 「弱反击」：反击伤害 = 攻击力 × 30%
- 「过河强化」：兵过河后 atk+30%
- 「冲锋」：兵攻击帅时 +50% 伤害

## 六、P3-1 角色技能体系调整（skilldesigner）

### 技能设计原则（Dota2 风格）

1. **每个角色必须有独特机制**（不能只是数值差异）
2. **弱角色针对性增强**（不是全面加强）
3. **强技能 CD 长，弱技能 CD 短**
4. **被动技能必须实际生效**

### 需要增强的弱角色

| 角色 | 当前问题 | 增强方案 |
|------|---------|---------|
| 王昕 | atk 80 过低 | 技能伤害提升 + 控场能力增强 |
| 周子翰 | def 80 但生存弱 | 瞬移后获得护盾 |
| 鸡哥 | def 68 过低 | 闪避机制 + 召唤强化 |
| ikun | 整体弱 | 节奏掌控 + 连击机制 |
| 唐昊博涵 | 技能单一 | 多重 buff + 真伤 |
| 刘佳伟 | 反击被动弱 | 反击伤害提升 + 持续削弱 |
| 袁清山 | atk 90 但 def 72 | 攻守转换机制 |
| 罗伦杰 | def 65 过低 | 连击 + 突进 |

### 技能标准化表

| CD | 单体效果 | AOE 效果 |
|----|---------|---------|

## 七、P3-2 故事模式剧情重做（storywriter）

### 风格定位

**斗破苍穹式网文套路**：
- 主角（玩家）从平凡开始，逐步变强
- B王 = 装逼反派，每次失败都不服气
- 每章有「装逼 → 打脸 → B王不服」循环
- 终章 B王彻底认输，主角成王

### 章节结构

每章必须包含：
1. **开场对话**（≥200字）：场景铺垫 + B王装逼
2. **对局**：玩家 vs B王
3. **胜利对话**（≥100字）：B王不服气 + 找借口
4. **解锁角色**：新角色加入

### 第一章示例（开场）

```

在本王面前，你们的智商就像是蚂蚁仰望星空——可望而不可即！

[主角（你）默默走进教室，看到这一幕]

「青铜装逼流」！
```
