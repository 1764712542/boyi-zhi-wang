# v30 综合大重构 · 平衡性 + 三系技能 + B王形态 + 新系统 + UI

## 背景

v29 完成后用户反馈新一轮问题，需进行大幅度综合重构：

### 用户反馈核心
1. **概率性光环需提醒**：5%走错/25%闪避等概率触发时无明显提示
2. **角色对话需可见**：对话放在左右两边头像，让玩家看见
3. **故事模式剧情看不到**：剧情未体现，需修复
4. **平衡性再次失调**：炮和车威力太大，马很一般
5. **三系技能体系重构**：所有角色技能需对应力量/敏捷/智力体系进行大幅调整
6. **B王负面人性是举例**：可参考七宗罪（傲慢/嫉妒/暴怒/懒惰/贪婪/暴食/色欲）
7. **选人界面新增三系分类**：力量/敏捷/智力三个标签页
8. **图鉴信息泄露**：图鉴里有函数描述，玩家看不明白，需修复
9. **图鉴同步更新**

### 用户选择的方向
- 特色方向（全选）：棋子升星/觉醒、天气/战场、Ban兵种、战场事件
- B王强化：形态切换
- 图鉴/成就（全选）：角色挑战成就、战绩统计、章节评分

### Phase 2: 三系技能体系重构（data.js + game.js + skills.js）

#### 2.1 三系定位明确化

**力量系（Strength）- 坦克/战士**：
- 核心机制：高HP、高防御、反击伤害、肉搏持久
- 技能特色：护盾、复活、反击强化、HP恢复
- 代表角色：胡浩、三金、周子翰、刘佳伟、布罗利、大汉棋圣、张树灿

**敏捷系（Agility）- 刺客/输出**：
- 核心机制：高攻击、高闪避、高移速、暴击
- 技能特色：瞬移、连击、闪避、突袭、混乱
- 代表角色：侯智博、陆星辰、鸡哥、ikun、袁清山、罗伦杰、刘锋

**智力系（Intellect）- 法师/辅助**：
- 核心机制：高技能伤害、短CD、真实伤害、控制
- 技能特色：沉默、禁锢、AOE、buff/debuff、真实伤害
- 代表角色：仙帝Alice、大爱仙尊、解宇轩、王昕、唐昊博涵、刘雪沛、帝国元首、张毓芝

#### 2.2 技能体系重构原则

每个角色的3个主动技能必须体现其所属系列特色：
- **力量系角色**：技能以护盾/反击/HP/复活为主
- **敏捷系角色**：技能以瞬移/闪避/连击/突袭为主
- **智力系角色**：技能以沉默/禁锢/AOE/真实伤害为主

**重构范围**：20个角色的主动技能全部重新设计（保留核心特色，调整机制匹配三系）

### Phase 3: B王形态切换系统 + 七宗罪技能（data.js + game.js + skills.js）

#### 3.1 B王形态切换

**机制**：B王每5回合切换一次战斗形态，玩家需适应变化

| 形态 | 特色 | 加成 |
|------|------|------|
| 防守型 | 龟缩防守 | 防御+30%，HP恢复+20/回合 |
| 进攻型 | 狂暴进攻 | 攻击+30%，技能CD-1 |
| 狡诈型 | 阴谋诡计 | 技能CD-1，buff持续时间+1 |
| 疯狂型 | 失去理智 | 随机攻击（含己方），攻击+50% |

#### 3.2 七宗罪技能重设计

B王7个主动技能对应七宗罪：

1. **傲慢（Superbia）**：气场压制对方全体攻击-25%，B王下次攻击+30%
2. **嫉妒（Invidia）**：复制对方一个被动技能给己方（持续3回合）
3. **暴怒（Ira）**：B王进入狂暴，3回合内攻击+50%但防御-30%
4. **懒惰（Acedia）**：让对方全体下回合无法移动远距离（≤1格）
5. **贪婪（Avaritia）**：窃取对方一个永久buff，B王回复30%HP
6. **暴食（Gula）**：吞噬己方一颗棋子，B王获得其HP和攻击的50%
7. **色欲（Luxuria）**：诱惑对方一颗棋子倒戈（控制1回合）

### Phase 4: 4大新系统

#### 4.1 棋子升星/觉醒系统

- 每颗棋子累积击杀数，达到阈值解锁强化形态
- **车**：3杀→攻+20%
- **马**：2杀→闪避+15%
- **炮**：3杀→无视60%防御
- **兵**：1杀→晋升为"卒长"攻防+30%
- **士/相**：2杀→反击伤害+50%
- **帅**：不升星（核心单位）

#### 4.2 天气/战场系统

- 每局开始随机生成天气，影响全局
- **晴天**：攻击+10%
- **雾天**：远程攻击命中率-20%
- **雨天**：火系技能伤害-30%（如有）
- **雷天**：每回合5%概率随机棋子触电掉血20

#### 4.3 Ban兵种系统

- PVP/online模式开局双方各Ban掉2个兵种类型
- 被Ban的兵种本局不出场
- 增加对局多样性

#### 4.4 战场事件/突发事件

- 每5回合触发一次随机战场事件
- **援军到达**：双方各+1兵
- **地震**：随机2颗棋子位移
- **迷雾**：3回合内不可见对方技能
- **宝箱**：随机一颗棋子+50%属性

### Phase 5: 图鉴/成就系统 + 信息泄露修复

#### 5.1 角色挑战成就

- 用每种角色击败B王一次解锁徽章
- 集齐全部20个徽章解锁隐藏奖励
- 徽章显示在图鉴首页

#### 5.2 战绩统计系统

- 记录：总对局数、胜率、最长连胜、击杀总数、技能使用次数
- 每周/每月更新
- 显示在主菜单

#### 5.3 章节评分系统

- 每章首通获得评星（1-3星）
- 20章共60星
- 全3星解锁特殊奖励

#### 5.4 信息泄露修复

- 删除图鉴中的函数描述（如 `case 'xxx'`、`passiveState.xxx`）
- 改为玩家可理解的中文描述
- 技能描述统一格式：效果+数值+持续回合+CD

#### 5.5 选人界面三系分类

- 选人界面新增3个标签页：力量/敏捷/智力
- 每个标签页显示该系角色
- 图鉴同步更新分类
